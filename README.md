# breakuptriage.github.io

A plain-language document describing **Breakup Triage** — a self-guided 35-day
protocol for the month after a breakup: 7 days of acute triage, then 28 days of
structured rebuilding. One short reading, one audio track, and one concrete task
a day.

- The document: <https://breakuptriage.github.io/>
- The course it describes: <https://breakuptriage.com/>

The page covers what the course is, how a day works, all 35 lessons and their
tasks, what it draws on, the rules it was designed to, what it is not, and why
it exists.

This repository hosts a single static page. The product, the lessons, accounts,
and payments live at the link above and are not part of this repository.

## Editing

Edit `index.html` and push to `main`. GitHub Pages publishes from the default
branch root, so there is no build step and no dependencies — plain HTML with
inline CSS and no JavaScript.

The copy mirrors the course itself. When a lesson, a stage, or the positioning
changes in the product, update this page in the same pass.

## Disclaimer

Breakup Triage is an independent educational publisher. The protocol is not
therapy and does not diagnose or treat mental health conditions. If you are in
immediate danger, contact your local emergency number or a crisis line listed on
the page.
