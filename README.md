# breakuptriage.github.io

The public project page for **Breakup Triage** — a self-guided 35-day protocol for
the month after a breakup: 7 days of acute triage, then 28 days of structured
rebuilding. One short reading, one audio track, and one concrete task a day.

- Project page: <https://breakuptriage.github.io/>
- The protocol itself: <https://breakuptriage.com/>

This repository hosts a single static page. The product, course content, accounts,
and payments live at the link above and are not part of this repository.

The page is plain HTML with inline CSS — no build step, no dependencies, no
JavaScript. It is published from the default branch root by GitHub Pages.

## Editing

Edit `index.html` and push to `main`. Pages redeploys automatically. The copy
mirrors the product's landing page; when the messaging changes there, update it
here too.

## Disclaimer

Breakup Triage is an independent educational publisher. The protocol is not
therapy and does not diagnose or treat mental health conditions. If you are in
immediate danger, contact your local emergency number or a crisis line listed on
the page.
